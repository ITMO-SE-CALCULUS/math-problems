# Задачи по матанализу и линейной алгебре

В этом репозитории публикуются **все задачи**, которые составляют банк заданий для контрольных точек в течение семестра.  

## Как проходит работа с задачами
1. Студенты могут самостоятельно решать задачи из списка для подготовки.  
2. В назначенный момент проводится **контрольная точка**.  
3. На контрольной точке студент **получает несколько задач** из общего списка и решает их при преподавателе.  
4. Баллы выставляются **только за решения, показанные на контрольной точке**.  
5. Домашнее решение задач — дело добровольное: оно помогает подготовиться, но напрямую не влияет на оценку.  

## Важные правила
- Во время контрольной точки **нельзя пользоваться никакими материалами**, включая записи, учебники, интернет и подсказки.  
- Проверяется именно умение решать задачи самостоятельно и объяснять ход решения.  

## Об использовании AI
Сервисы на основе искусственного интеллекта могут быть полезны для проверки отдельных шагов или поиска идей.  
Тем не менее:  
- на контрольной точке доступ к ним будет невозможен;  
- они не могут заменить полноценной подготовки;  
- реальный навык решения формируется только при самостоятельной работе.  

Используйте такие инструменты **только как вспомогательный ресурс**, основа подготовки — ваши собственные решения.
